# 新增單字最終複查

對新增的 **240 個單字**進行獨立逐筆複查：職場、旅行、商務、日常各 60 個。來源為 `src/content/work-additions.ts`、`travel-additions.ts`、`business-additions.ts`、`daily-additions.ts`，並閱讀整合後的 `src/data.ts` 資料。原有 80 個單字的複查另見 `content-word-review.md`。

每筆閱讀範圍為美式音標、詞性、中文意思、英文定義、原創例句、中文翻譯及搭配用法，確認所選詞義與例句用途一致。這輪未發現需修正的主要詞義、詞性或美式讀音錯誤。
