# 原有單字內容複查

本次逐一複查原有 80 個單字，範圍包含音標、詞性、中文義、英文定義、例句、例句翻譯與搭配用法。所有原有 ID 均保留，以維持收藏和學習紀錄相容性。

## 修訂重點

| 項目          | 修訂與理由                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| `deadline`    | 將 `meet a deadline` 譯為「在期限內完成」，比「遵守截止期限」更符合中文慣用表達。                    |
| `prioritize`  | 將交貨延遲顧客的關係明確寫出，避免中文修飾結構難讀。                                                 |
| `initiative`  | `take the initiative` 改譯「主動採取行動」。                                                         |
| `destination` | `business retreats` 改譯「企業團隊移地研習」，避免只解釋成休憩。                                     |
| `recommend`   | 定義同時涵蓋「推薦選項」及「建議採取行動」，與 `recommend reviewing` 例句一致。                      |
| `consistent`  | 明確表達「每月只集中讀一次、一次讀數小時」的比較情境。                                               |
| `fare`        | 例句改為票價包含劃位，避免 `includes ... one small bag` 讓初學者誤會票價包含行李本體，而非行李額度。 |
| `refundable`  | 定義明確指出可以退回的是已支付的款項，也適用於 `refundable tickets/deposits`。                       |
| `merchandise` | 將 `damaged` 直接譯為「受損」，保留原句語意。                                                        |
| `participate` | 將 `are encouraged to` 譯為「鼓勵」，較「歡迎」更直接對應原句。                                      |
| `accessible`  | 翻譯保留輪椅使用者可使用設施的語意，不另推論具體設備配置。                                           |

## 音標與程度標示

原有音標採常見美式讀音，未發現明顯的音節、主要重音或詞性讀音錯置。`/e/` 與 `/ɛ/`、以 `/t̬/` 標記美式閃音等屬字典轉寫方式差異，不宜當作不同的單字讀音。此項為編輯複查，未聲稱逐筆經外部字典認證。

原有 `TOEIC 550–700`、`600–750`、`650–800` 是編輯估計，不是 ETS 官方逐字分級。建議統一為網站的選材目標並在介面與文件說明，避免讓學習者將標籤理解為官方分數對照。

整合結果：全部 320 個詞條已統一標示「700 分目標詞彙」，並已在單字頁及 README 說明屬於編輯選材；上述 11 項修訂已直接套用至 `src/data.ts`。

本次修訂聚焦於教材的一致性與清楚程度；不將自動化欄位測試當成語言內容已經過外部認證的證明。
