# 從約 700 分走向 800+ 的單字路線

學習者目前約 TOEIC 700 分，目標是 800 分以上，同時希望補足容易遺忘的單字。因此教材保留較基礎的生活與職場詞，也延伸到高分閱讀中的正式商務用語；不只把所有內容一律提高難度。

## 三個練習帶

| 分組     | 練習帶  | 選材用途                                                                       |
| -------- | ------- | ------------------------------------------------------------------------------ |
| 基礎鞏固 | 600–700 | 常見生活、交通、工作與交易詞；重點是能快速回想、辨認搭配，不因目標提高而跳過。 |
| 800+核心 | 700–850 | 公告、會議、工作流程、旅宿與商務信件常用詞，兼顧語意、詞性與搭配。             |
| 高分延伸 | 850–990 | 較正式或較專門的用字、金融與採購概念，以及需要依語境辨別的指定詞義。           |

這些是本站的編輯選材與練習目標，**不是 ETS 官方逐字分級**。分數區間不表示「認識這個字就有某個分數」，也不是學習者能力的自動測量。單字熟悉度會因個人經驗、所選詞義及語境而不同。

## 480 個詞條的分類方式

已逐項檢查原有 320 個詞條的指定詞義與用途，將每個 ID 明確對應一次，沒有以未分類字一律歸為核心的程式預設。

新增的 160 個詞條也逐項依實際詞義重新分類，不因它出現在擴充批次的 `*-advanced.ts` 檔案中，就一律稱為進階。完整分布如下：

| 範圍     | 基礎鞏固 | 800+核心 | 高分延伸 | 合計 |
| -------- | -------: | -------: | -------: | ---: |
| 原有詞條 |      150 |      144 |       26 |  320 |
| 新增詞條 |        2 |       71 |       87 |  160 |
| 全部詞條 |      152 |      215 |      113 |  480 |

保留常見單字作為基礎，例如 `employee`、`reservation`、`payment`、`available`。較廣的職場用字，如 `prioritize`、`coordinate`、`inventory`、`eligible`，列為核心。`compliance`、`correspondence`、`liability`、`equity`、`procurement` 等較正式或專門的詞義列為高分延伸。

分類依據是教材實際使用的詞義與搭配，不單看字長。例如 `minutes` 教的是「會議紀錄」而不是時間單位；`turnover` 教的是員工流動；`outstanding` 教的是尚未支付。這些詞應配合各自例句學習，不把一個標籤套用到該字的全部意思。

新增詞中，`inconvenience` 常出現在服務通知的慣用句，`recyclable` 是常見消費與回收說明，因此保留在基礎。`allocate`、`mandatory`、`tentative`、`layover`、`restriction`、`exclusive`、`obligation`、`compatible`、`sustainable` 等列為核心。`discretion`、`grievance`、`scrutiny`、`collateral`、`insolvency`、`depreciation`、`stipulate`、`berth`、`proximity`、`biodegradable`、`sedentary` 等較正式、較少見或較專門的指定詞義列為高分延伸。

這些邊界是學習安排，不是對某一個字設立固定門檻。例如有金融工作背景的人可能早已熟悉 `liquidity`，沒有相關經驗的人則需要先理解例句中的概念；兩者都可保留在自己的收藏或練習中。

## 每日混合練習

每天 10 個單字建議以 **3 個基礎鞏固、5 個核心、2 個高分延伸**為起點。基礎不足時可先多練基礎，已熟悉時則可切換核心或進階，不必一次背完整個詞庫。

每日混合練習應從尚未掌握的詞中取材，並輪換情境分類；某一組不足時，再由其他尚未掌握的詞補足。這是安排練習負擔的策略，不是分數預測公式。

## 本輪新增內容複查

新增 160 詞依職場、旅行、商務、日常分成四批，各 40 詞。每批均逐項自校，再由另一批編輯交叉複查音標、指定詞性與詞義、定義、雙語例句及搭配；原有詞條語言內容保持不變，只增加學習分組。

本輪修正包括 apprenticeship 音標補上遺漏的 `/s/`、embark 例句明確使用碼頭而非容易聯想到機場的航廈、scenic 避免把 highway 一律與公路對立、carrier 明確指航空運輸業者、insolvency 說清楚客戶付款延遲，以及 maturity 保留「直到到期」的時間語意。infectious 定義也避免將所有感染性疾病限縮為人與人直接傳播。

這些是實際語言內容複查，資料完整性與介面測試另行執行；不將測試通過當成所有自然語言用法都獲得外部認證的證明。

## 資料與進度相容性

保留原有單字、文法及題目 ID。新增學習分組只改變教材的分類與練習安排，不重設收藏、已掌握、文法完成或錯題紀錄。原有備份仍可對應到既有詞條。

分類表在 `src/content/vocabulary-tiers.ts` 明列全部 480 個詞條；已核對總數、原有與新增 ID、每個 ID 的唯一性，以及與整合後資料的完整對應。未分類的新 ID 應在整合與資料檢查時被發現，而不是靜默套用預設分組。這是編輯分類與資料完整性查核，沒有宣稱逐筆獲得外部詞典的難度認證。
