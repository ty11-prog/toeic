# daylight. 英文學習手帖

每天一點，英文更近一點。參考 [拾語手帖](https://github.com/ty11-prog/japanese) 的自學流程，為目前 TOEIC 約 700 分、目標 800 分以上的學習者打造繁體中文英文學習網站。單字選材橫跨 600–990 的練習需求，保留基礎補強，也提供高分閱讀延伸。

暖白、鼠尾草綠與淡杏色介面，搭配本機打包的中英文字型。支援桌面、平板與手機，免登入、免 API 金鑰。

## 開始開發

使用 Node.js 22.12+（已驗證 Node.js 24）與 npm：

```bash
git clone https://github.com/ty11-prog/toeic.git
cd toeic
npm ci
npm run dev
```

正式建置、測試與本機檢查：

```bash
npm test
npm run build
npm run preview
```

## 學習內容

- **480 個情境單字**：職場、旅行、商務與日常生活各 120 個，含美式音標、中文意思、英文定義、雙語例句與常見搭配。單字卡每批顯示 24 筆；搜尋與單字卡練習涵蓋全部符合篩選的單字。
- **三個練習帶**：基礎鞏固 600–700（152 字）、800+核心 700–850（215 字）、高分延伸 850–990（113 字）。可混合練習，或搭配情境與搜尋分級篩選。
- **每日混合學習**：以 3 個基礎、5 個核心、2 個進階字為原則，優先選尚未掌握的單字，並輪換情境；某組不足時由其他新字補足，全部掌握後才切換成複習。
- **12 篇文法主題**：完成式、被動語態、關係子句、條件句、動名詞、連接詞、詞性、主動詞一致、分詞、比較級、可數與不可數名詞，以及時間介系詞。
- **40 題附解析練習**：單字與文法各 20 題。每次隨機抽取最多 10 題，支援專項練習、錯題收錄與答對後移除。
- **單字卡**：先回想再揭示解答，自評是否記住；已掌握的新字與首次完成的文法才計入活動，避免重複點擊灌入進度。
- **收藏與學習足跡**：即時搜尋、分類、收藏、每日目標、連續學習、近七日活動與歷次測驗摘要。
- **進度備份**：匯出 JSON；匯入時檢查資料，先預覽並確認，再取代目前進度。
- **手機分頁**：下方固定提供「今日、單字、文法、足跡、設定」，保留原選單；展開選單或開啟學習視窗時收起分頁列，並預留手機安全區域。
- **例句朗讀**：每日例句、單字卡例句及文法例句均可播放與停止；測驗作答後也能聽填入正確答案的完整句子。
- **語音設定**：提供美式、英式、澳洲英文偏好，選擇裝置可用的英文聲音、調整 0.60–1.20 倍語速及試聽。設定會保存在目前瀏覽器，套用於所有單字與例句。

這是針對目前約 700 分、目標 800+ 的學習者設計的原創教材，不是完整題庫或官方分數預測。三個分組與 600–990 分數練習帶，是本站依實際詞義與用途安排的編輯選材，並非 ETS 官方逐字分級；認識某個單字不表示能力等於該分數。測驗百分比表示本站練習的答對比例。

原有 320 個單字、12 篇文法與 40 題測驗已逐項複查；這次另新增 160 個延伸詞條，經自校與跨批次複查，再對全部 480 個詞條明確分類。原有單字、課程與題目 ID 均保留，原有收藏與備份仍相容。既有修訂理由見 [內容複查紀錄](docs/content-review.md)，本次選材與分類見 [700 → 800+ 單字路線](docs/vocabulary-800-plan.md)。語言編輯複查與自動化資料完整性測試分別進行，後者不代表外部詞典或官方認證。

## 本機資料與發音

學習進度儲存在目前網站的瀏覽器 `localStorage`，沒有帳號或雲端同步。清除網站資料、使用無痕模式、改用另一個瀏覽器或網站網址，都可能無法保留進度；請在「學習足跡」定期匯出備份。匯入備份會取代現有資料，建議先匯出目前的進度。

英文朗讀使用瀏覽器的 Web Speech API，實際聲音、可用性與是否需連線依裝置而異；無法播放時仍可閱讀音標及例句。網站未實作離線快取。

可從「語音設定」試聽裝置的不同聲音。自動模式會優先匹配所選口音，並參考 Natural、Enhanced、Premium、Neural 等名稱；這些名稱只是選聲提示，不保證音質或語音技術。指定聲音以其實際口音朗讀；若換裝置後找不到原聲音，會保留偏好並暫時改用其他英文聲音。沒有英文聲音或不支援語音時，介面會顯示說明。系統合成語音並非真人錄音，也沒有額外的雲端配音服務或 API 金鑰需求。

語音偏好獨立存於 `daylight-speech-settings-v1`，不會改動學習進度；目前 JSON 進度備份不包含語音設定。播放期間可按原按鈕停止，切換頁面、關閉學習視窗或切換到下一題／單字會停止朗讀。

## 部署

`npm run build` 產生 `dist/`，可部署至一般靜態網站服務。資源使用相對路徑，支援 GitHub Pages 的 `/toeic/` 子路徑。

專案附有 `.github/workflows/deploy.yml`。將 GitHub 儲存庫的 **Settings → Pages → Source** 設成 **GitHub Actions** 後，每次推送至 `main` 都會自動測試、建置並部署；也可在 **Actions → Deploy daylight. to GitHub Pages → Run workflow** 手動發布。

預設發布網址為 `https://ty11-prog.github.io/toeic/`，實際部署結果請以 GitHub Actions 的成功紀錄及網址回應為準。
